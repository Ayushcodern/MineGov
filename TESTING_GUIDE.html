📋 MineGOV — Quick Testing & Demo Guide

AI-powered, offline-first compliance, mine safety inspection, and coal transport traceability application for Indian Coal Mines (CMR 2017).

🚀 1. How to Run the App

Open your terminal and run one of the following commands:

cd d:\sihminegov\minegov\MineGOV\cm-gip-mobile
npx expo start -c

💡 If testing on a physical mobile phone across different Wi-Fi networks:

npx expo start -c --tunnel

💻 To run directly in your Web Browser:

npm run web
